**MindSync: Agentic AI Wellness Solution**
MindSync is an AI-powered personal wellness assistant designed for the HealthTech track. Its core goal is to help users effortlessly achieve balance across work, social life, and personal well-being by moving beyond passive tracking to proactive, personalized intervention using Agentic AI.

**Description of the Solution:**
1) Home Screen & Multilingual Support
The home screen is the central hub, displaying the "Your Balanced Day" schedule and proactive AI Assistant Suggestions (e.g., "You've been working intensely this week. Consider calling your parents tonight."). The platform supports a multilingual interface for broad accessibility.

2) Wellness Dashboard
The Dashboard provides a clear, high-level overview. It tracks a Weekly Wellness Trend comparing aggregated wellness and stress levels, and monitors key metrics like Daily Steps, Daily Stress, and Sleep Hours against personalized targets.

3) Diary Feature (Mood Analysis via NLP/LSTM)
Users input a Daily Reflection text entry. The AI instantly processes this text for AI Mood Analysis. This feature is powered by a Long Short-Term Memory (LSTM) / Bi-LSTM deep learning model using Natural Language Processing (NLP) to accurately infer and quantify the user's emotional state from the text.

4) Facial Emotion Recognition (FER)
MindSync offers a real-time emotion detection feature via the live camera feed. It uses a Convolutional Neural Network (CNN)-based model for Facial Emotion Recognition (FER) to provide a multi-modal, objective check on the user's current emotional state (e.g., classifying 'angry' or 'happy').

5) Task Manager Agent
The Task Manager features an AI Scheduling Assistant that operates as an Agentic AI. It interprets a user's natural language request (e.g., "Schedule a meeting tomorrow at 2pm") and autonomously takes action to manage and update the calendar. It also offers proactive AI Recommendation for maintaining productivity and balance.
